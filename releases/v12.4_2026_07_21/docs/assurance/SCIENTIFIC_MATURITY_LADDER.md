# MathGov Scientific Maturity Ladder

**Status:** Informative claim-boundary and research-planning companion.

| Level | Evidence question | Current v12.3 status |
|---|---|---|
| L0 Source integrity | Are artifacts readable, versioned, hash-pinned, and reproducible as files? | Strong internally after final verification; public canonical status still requires repository and website synchronization |
| L1 Formal conformance | Does an independent implementation reproduce equations, typed states, and vectors? | Partial; workbook and vectors exist, reference semantics/evaluator remain future work |
| L2 Reliability | Do independent evaluators reach sufficiently similar classifications and scores? | Not established at framework scale |
| L3 Construct validity | Do measures capture distinct intended constructs without category collapse? | Protocols and safeguards exist; empirical evidence incomplete |
| L4 Decision validity | Does use improve decision quality, harm detection, or accountability against comparators? | Not established |
| L5 External validity | Does performance generalize across cultures, domains, institutions, and substrates? | Not established |
| L6 Deployment assurance | Does the system remain safe, secure, corrigible, and effective under adversarial high-stakes use? | Not established |

## Rule

Documentation completeness, formula consistency, and successful release verification are L0-L1 evidence. They must not be presented as L2-L6 evidence.

## Release wording

The current package is a Tier 1-3 research/source specification with strong source-integrity controls and partial formal-conformance scaffolding. It is not empirically validated, deployment-certified, or proven superior.
