# V12.0 Complete-Ready Computational-Source Boundary Report

Release: MathGov Core Release 2026.09 v12.0 Physical Admissibility Release

This complete-ready refinement keeps the same public versions and core cascade while adding a small but material clarification: candidate generation is not admissibility verification.

## Integrated improvements

- Added `candidate_generation_source` and `admissibility_warrant_source` language to PC-AEP.
- Clarified in the Canon that a generated candidate is not a verified admissible transition.
- Clarified in the Cascade Standard that orchestration, filtering, guardrails, policy routing, monitoring, and approval do not establish physical or causal safety by themselves.
- Added a computational-source boundary to Source-Coupling Integrity, Agent System runtime rules, MFDI, README, and the physical-admissibility guide.
- Added non-claim language: MathGov does not prove that any particular compute class is necessary or sufficient for AI safety; it only requires evidence-bound distinction between candidate generation and admissibility warrant.

- No sixth gate.
- No cascade change.
- No equation change.

- No workbook formula change.
