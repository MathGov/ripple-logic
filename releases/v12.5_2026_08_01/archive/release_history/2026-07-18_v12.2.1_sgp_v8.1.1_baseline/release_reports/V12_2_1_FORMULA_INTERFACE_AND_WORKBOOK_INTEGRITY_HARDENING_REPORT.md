# v12.2.1 / SGP v8.2 Formula, Interface, and Workbook Integrity Hardening Report

## Audit disposition

The GPT-5.5 Pro feedback was materially useful but mixed. The formula/interface findings were checked against the shipped bytes and integrated only where the defect was present. Claims already disproved by the current package were not reintroduced.

### Accepted

- workbook sanity-summary contradiction;
- MPS interval versus welfare-hypothesis type conflict;
- U7 Equity `NA` versus fixed-one fallback conflict;
- missing `/Q` in companion RLS formula surfaces;
- `m_{k,x}` versus `h_{k,x}` stream-coefficient error;
- stale tier-proportional CSV language and status tokens;
- incomplete three-channel NCRC disclosure in examples;
- unresolved PLSS prominence sensitivity paired with excessive publishability wording;
- Agent self-audit challenger, CSV, decisiveness, and authority-selection weaknesses;
- ambiguous “70 intersections” wording.

### Partially accepted

- RMCP arithmetic was retained but explicitly limited to a heuristic ordinal-profile summary.
- ripple.md remains comprehensive; its conformance boundaries were preserved rather than reduced for length alone.
- mechanical reproducibility remains bounded: a schema and semantic validator exist, but full ProofPack/reference-calculator assurance does not.

### Rejected as stale or inaccurate

- the current package does not contain Markdown masquerading as DOCX; all active DOCX files are valid OOXML;
- README, LICENSE, manifests, hashes, and release support are present;
- the Component Map already carried current pins before this patch;
- final workbook NCRC already depended on the Rights_Hardening surface;
- no sixth gate or conceptual redesign was required.

## Result

The patch changes only the components whose semantics, formulas, or current examples changed. The governing cascade remains `RG -> RF -> TRC -> CSV -> RLS`. The package remains a Tier 1-3 research/source and validation-preparation release, not empirical validation or deployment certification.
