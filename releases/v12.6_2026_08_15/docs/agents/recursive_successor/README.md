This package updates the runtime companion architecture without modifying the MathGov Canon. Its central rule is:

> **Intelligence may create a candidate successor; it may not create the successor's authority.**

## Scope boundary

This package does not assert that open-ended recursive self-improvement is established or imminent. It governs material descendants, self-modification, retraining, composition, autonomy changes, and successor development whenever old authority might otherwise be inherited by a new technical configuration.
