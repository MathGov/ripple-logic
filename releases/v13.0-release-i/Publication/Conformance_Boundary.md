# Publication and conformance boundary

This is a research/teaching specification, a frozen worked example, and a scoped reference-testing package. Source completeness and reproducible arithmetic are not empirical validation or execution authority.

| Surface | This package establishes | Not established |
|---|---|---|
| Core masters | 14 controlling DOCX specifications, one hash-pinned frozen XLSX example | Universal ethical truth or calibrated welfare units |
| Reference tests | The supplied equations, derived records, artifact checks and synthetic cases | Full external v4.1 run-record/schema/registry conformance |
| Workbook | Exact file identity and fresh cache-independent replay; G native receipts retained only as source-build evidence | New native I recalculation/save/reopen, Microsoft Excel parity, arbitrary spreadsheet-engine compatibility, editable operational selector |
| ripple.md | L0/L1 learning and basic Decision Note practice | Standalone L2/L3 conformance requiring unbundled RPAP/PFAP |
| WDBIP | Current v1.9 prose and documented classification/record requirements | Verified v1_7 schema-to-v1.9 semantic parity |
| Maturity | Public reviewable research specification | V0/V1 or R0/R1 for an arbitrary run merely because it uses the Core; R2 independent replay without another implementer; R3/R4 or Tier 4 |
| Publication | Local immutable release staging and checksums | Live repository/site synchronization or hosted CI |

Do not remove stronger conformance requirements to make a release label pass. Consult Dependency_Status.json, the verification report and each controlling source. MHIOS, Auditable Flourishing and AIAP are outside the Core 15 and inherit no assurance from it.
