4. The local verdict-display limitation remains explicit

A disposable overwrite of RLS!B40 with SELECTED_DECISIVE leaves the local Build_Integrity!B14 result at zero. This is the documented non-circular guard boundary, not a repaired detector. The separate actual-file mutation test verifies that Workbook_Verifier rejects the mutated XLSX against the trusted manifest. Equal-result alternative formulas and jointly edited snapshots likewise require the external integrity layer. File integrity is not evidence truth, rights compliance or execution permission.

The original worked result remains RLS(A) = 0.0153129427168233 and RLS(B) = -0.00112238738505248. Nominal Gap is approximately 3.56552 and the doubled-uncertainty value is approximately 1.81508. The framework therefore retains REFUSE_DETERMINISTIC_SELECTION, with authority choice separately disclosed. No patch manufactured a framework winner.
