# Records and display integrity

## Purpose
Make the mathematical field inspectable without confusing its display with evidence, qualification or authority. This is an informative implementation profile beneath the Canon, WDBIP and Agent System. It introduces no additional gate and grants no execution permission.

## Distinct records
An observation identifies the measured variable, units, source, configuration, observation time, receipt time, validity boundary, freshness and uncertainty. An effect record identifies the bearer/system, changed construct, baseline, causal or descriptive warrant, stable effect identity, primary computational home and any view-only references. A snapshot is a derived 7 × 7 field and contribution matrix. A decision record separately references qualification, uncertainty, robustness, framework verdict and any lawful authority decision. An action record distinguishes proposal, authorization, attempt, acknowledgement, observed effect and unresolved outcome.

The supplemental schemas under Reference cover only an illustrative effect transition and a qualified-control timing record. They are not replacements for the entire legacy Canon run-record, SGP, WDBIP or operator-envelope schema families. Unknown effects carry an explicit state rather than a fabricated numerical zero. A supplied number does not establish that the underlying construct is valid.

## Display contract
Use stable U1–U7 and D1–D7 identifiers. Bind values to named fields, not incidental JSON property order. Show signed impacts and signed contributions with a visible zero reference. Show missing, contested and out-of-domain cells as labelled states, never as an empty-looking zero. Always distinguish raw telemetry from a normalized impact and from its weighted contribution.

For a numerical RLS, display the cell contribution matrix, its row margins and its column margins. Each margin family independently sums to the same score; adding both families doubles the accounting. Display positive and negative contribution totals separately. Do not imply that causal source attribution is additive through nonlinear saturation. Display the active weight mass and the rounding precision needed to interpret small contributions.

The qualification record precedes any winner label. A point-score leader may coexist with REFUSE_DETERMINISTIC_SELECTION. Authority selection, action authorization and observed outcomes remain separate. No interface may infer a health, coherence, safety or alignment percentage from the fact that a request completed, a schema parsed or a service is online.

## Acceptance evidence
Test permutation of object properties, negative harms, positive benefits, missing fields, numerical zero, NaN/Infinity rejection, stale data, all-inactive weight mass, non-decisive leaders and discrepancies between a source field and its cached display. Verify keyboard/text accessibility and ensure the interface remains understandable without color. UI test passage establishes interface behavior, not evidence truth.
