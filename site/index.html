TRANSPARENCY & LIMITS

What the evidence supports

This is a Tier 1–3 research-and-teaching specification with a bounded worked example and scoped reference tests. Passing checks does not establish empirical validity, production readiness, legal authority, safety certification, or Microsoft Excel certification.

Release I records eight reproduced errata. No new native Excel recalculation/save/reopen was performed for I; earlier application receipts remain evidence for their original build.

  • Corrections and adjudication
  • Verification scope and results

This maintained page reflects the GitHub publication. The original frozen index and manifest preserve preparation-time statements, including “not published”; they are historical records, not the current hosting status. Release assets include the publication and hosting receipts.

REPRODUCIBILITY

Run the scoped checks

Use Python 3.13 and Node.js 22 on Linux, matching hosted verification. After cloning the repository, run:

python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-ci.txt
python -B releases/v13.0-release-i/verify_all.py --output-dir ../mathgov-results

The standalone publication ZIP needs an additional timestamp-validation dependency. Follow the complete installation instructions for ZIP, repository, and Windows use. Keep generated output outside the frozen publication.

Help make the work more rigorous

Bring a reproducible discrepancy, a precise counterexample, or a source-backed correction. Identify the build and component so another reader can examine the same evidence.
